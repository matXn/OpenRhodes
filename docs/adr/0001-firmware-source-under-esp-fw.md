# 0001 当前固件位于 `esp_fw/`

日期：2026-10-27（记录日期）

状态：现状记录；历史决策理由待确认

## 背景

仓库保留了根目录的早期固件，也有整理后的 `esp_fw/` 项目。两者各有构建配置，在不同目录运行 PlatformIO 可能得到不同固件。

## 当前做法

当前固件的开发、构建和测试使用 `esp_fw/`；根目录早期固件保留作历史基线。

## 影响

- 当前固件的构建命令在 `esp_fw/` 下运行。
- 根目录与 `esp_fw/` 的代码和参数可能不同，须避免将早期基线误当作当前固件。
- Android 客户端位于仓库的 `app/`，有独立的构建说明。

## 待确认

整理时评估过的替代方案和保留历史基线的具体原因尚未在此记录；不应将推测的理由视为团队已批准的决定。
