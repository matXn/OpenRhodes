# 0003 BLE 配网使用 Security 1 且不要求配网码

日期：2026-10-27（记录日期）

状态：当前实现记录；产品安全决策待确认

## 背景

设备支持通过 BLE 提交 Wi-Fi 配置信息。当前实现使用 Espressif Security 1，未启用可选的所有权证明（PoP）。

## 当前行为

- 使用 X25519 和 AES-CTR 建立加密会话，但不要求输入配网码。
- 未经所有权证明的 BLE 配网不能防止主动冒充；开启期间附近设备可能发起配网。
- BLE 初始窗口至少五分钟；已入队的请求在解码前会延长窗口。
- 窗口到期时，若**当前**已保存网络列表不为空，BLE 服务停止；若列表为空，则继续开放。即使此前成功配网过，删除全部配置后也可能重新进入列表为空的状态。
- 旧的 `rhodes-net/ble-pop` NVS 数据保留，但当前实现不使用它。

## 待确认

是否采用物理在场确认或其他所有权验证，以及无已保存网络时的开放策略，需要产品和安全评估。此记录不代表已批准相关风险。

协议细节与其限制见 [`esp_fw/docs/bluetooth-provisioning.md`](../../esp_fw/docs/bluetooth-provisioning.md)。
