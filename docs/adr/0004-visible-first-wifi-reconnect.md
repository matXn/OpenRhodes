# 0004 自动重连采用可见网络优先策略

日期：2026-10-27（记录日期）

状态：当前实现记录；历史决策理由待确认

## 背景

设备可保存多个网络；启动时需要在自动重连与用户打开配网页、扫描和手动连接之间协调无线电使用。

## 当前行为

自动连接先进行异步全信道扫描，按已保存的优先级尝试可见网络，并为每个 SSID 使用扫描观测到的最强信道。未发现的网络作为兜底候选。自动尝试收到 `NO_AP_FOUND` 时，在至少 1.5 秒后可提前结束；其他情况仍可能等待完整的 25 秒超时。

配网页打开时，正在进行的扫描可与页面共享，自动选择会被抑制。显式连接请求与自动重连有不同的处理规则。

## 影响与限制

- 可见网络优先及特定错误的提前结束有助于减少部分场景下的等待，但不保证最坏情况只需几秒；多个网络依次超时仍可能耗时数分钟。
- 扫描不修改已保存的网络优先级。
- 实际连接时长取决于射频环境、网络状态和失败类型。

详细行为见 [`esp_fw/docs/wifi-setup-priority.md`](../../esp_fw/docs/wifi-setup-priority.md)。
