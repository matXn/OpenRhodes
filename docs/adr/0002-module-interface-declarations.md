# 0002 拆分 HTTP 声明与实现

日期：2026-10-27（记录日期）

状态：本次重构记录；长期架构约束待确认

## 背景

此前 `main.cpp` 中途包含 HTTP 与 BLE 实现头，BLE 所需的部分声明依赖包含顺序。将两个头文件对调时，编译首先因 `jsonQuote` 未声明而失败。

## 本次改动

HTTP 和配网实现移入 `http_control.cpp`，`http_control.h` 提供跨文件声明；板级配置和跨模块声明分别放入 `board_config.h`、`light_contract.h` 和 `ble_contract.h`。BLE 实现头显式包含其所需头文件。

## 影响与限制

- 当前固件可完整编译链接；特定的 BLE 和 HTTP 头文件顺序对调也已验证通过。
- 此改动没有把 BLE 实现迁出 `ble_provision.h`。该头仍含函数与全局定义，不能安全地被多个翻译单元重复包含。
- 目前网页资源由 HTTP 实现引用；将资源同时引用于多个翻译单元可能增加 Flash 使用量，拆分时应重新构建测量。
- 部分主机测试通过抽取函数和替身运行，并不等价于完整固件的跨翻译单元集成测试。

## 待确认

BLE 实现是否也要迁出头文件，以及更广泛的模块边界，应在后续设计中决定。
